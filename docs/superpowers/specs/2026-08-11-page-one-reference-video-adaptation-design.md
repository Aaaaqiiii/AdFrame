# 页面一：参考视频广告改编设计规格

**状态：** 已获用户确认，待用户审阅本文后编写实施计划
**范围：** 仅页面一；页面二（替换产品）和页面三（原创分镜）不在本期内。
**部署起点：** Windows 本地服务器；架构预留未来外网部署。

## 1. 目标与边界

用户上传 4–30 秒的参考广告视频，在保持原视频产品不变的前提下，编辑人物、背景、动作、运镜或指定时间段；系统生成并展示可编辑的按时间段提示词，用户确认后选择火山方舟官方或 Comfly 提交 Seedance 2.5。

系统不保证逐帧还原、不替换产品、不自动把镜头拆成独立生成任务，也不在第一版自动判定生成视频合格或不合格。

超过 30 秒的视频仍可完成分析与提示词生成，但提交前必须阻止并提示用户更换或裁剪参考视频；系统不擅自分段提交。

## 2. 用户流程

1. 创建项目并上传参考视频；后端保存原始文件，读取时长、分辨率、帧率、方向和音轨信息。
2. 视频理解：火山视频理解负责整段广告语义与逐镜视频理解；FFmpeg 提供精确时间戳、候选切点和关键帧；GPT-5.6 仅用于关键帧细节复核和结构化提示词整理，不作为视频理解主模型。
3. 生成 AI 初始时间轴：保存整段摘要、候选镜头、关键帧、观察事实、推断和不确定项。
4. 人工校正：用户可拖动镜头边界、在播放位置拆分、合并相邻镜头与按帧微调。确认后的人工时间轴为权威版本；只重新分析受影响镜头，初始 AI 版本保留为历史。
5. 编辑改编：选择镜头或时间段，分别修改人物、背景、动作、运镜或整个镜头；每次修改保存前后差异和保持不变项。
6. 检查最终提示词：展示按时间段生成的完整提示词，允许用户直接编辑并确认。
7. 选择生成设置：选择火山官方或 Comfly；设置音频；可选启用人物参考图片；提交前执行输入校验。
8. 提交与追踪：提交完整参考视频和最终提示词，立即持久化任务 ID；后台 Worker 轮询状态，页面关闭和服务重启后可以恢复。
9. 结果：成功后展示、下载并保留结果视频。可基于当前版本直接重新生成或修改后新建版本；旧结果不覆盖。

## 3. 编辑规则

### 产品锁定

页面一锁定原产品身份。用户可以更正 AI 对原产品 Logo、包装文字、颜色或结构的识别事实，但不能把它替换成另一款产品；包含产品替换的最终提示词不允许提交。

### 一镜到底

若 AI 未识别出真实切镜，默认只显示一个连续镜头，避免展示不必要的复杂编辑器。用户可选择“添加编辑区间”，在同一镜头内按时间段改变人物、背景、动作或运镜；这些区间不被解释为原视频存在切镜，系统要维持角色、产品、机位和场景的连续性。

### 素材与人物参考图

人物与背景支持文字描述和图片上传。图片会先被视觉模型转换为可编辑文字档案，用户确认后参与提示词。人物图片另有一个默认关闭的开关“同时作为生成参考图”；开启后图片以 `reference_image` 随请求提交。上传真人素材时，用户必须确认已获得授权；官方通道按需要使用其可信素材/Asset ID 路径。

### 音频

使用固定选项。默认“保持原 BGM”，即不向提示词加入音频要求；用户只有选择某种音频风格时，系统才将该风格加入最终提示词。默认选项不承诺模型会字节级保留原音轨，生成结果由用户试听。

## 4. 页面与交互

主编辑台采用三栏布局：左侧显示工作流步骤与镜头列表，中间显示原视频和可编辑时间轴，右侧显示当前时间段的修改表单。时间轴和镜头列表始终同步，用户可从任一入口切换当前编辑对象。

人工校正时间轴是独立编辑态，提供拖动边界、拆分、合并、按帧微调、恢复 AI 初始划分和确认划分。确认前不覆盖此前的 AI 版本。

最终提示词、供应商选择、音频选项与提交检查置于编辑台的下一步骤，避免与分镜编辑混在同一屏幕。

## 5. 服务结构

- **React 前端：** 上传、原视频预览、时间轴、编辑表单、提示词确认、任务和结果页面。
- **FastAPI 后端：** 业务 API、项目与版本管理、密钥隔离、文件元数据、生成请求构建。
- **PostgreSQL：** 项目、素材、镜头版本、提示词版本、生成任务、结果版本和错误记录。
- **独立 Worker：** 视频元数据提取、关键帧、视频理解、受影响镜头重分析、素材临时上传、供应商提交、轮询和结果下载。
- **本地文件目录：** 本地开发阶段保存原始素材、关键帧和结果文件；将来可由对象存储替代。

第一版不引入 Redis、Docker、账户注册、计费或自动质检。所有 API Key 只读自服务端环境变量，绝不返回前端或写入日志。

## 6. 视觉模型与生成供应商

火山视频理解作为整段和逐镜视频理解主路径；GPT-5.6 Terra 用于关键帧细节复核及提示词结构化，高风险任务可以切换 GPT-5.6 Sol。封装统一视觉服务接口，以便未来替换。

生成供应商同时支持：

- 火山方舟官方：`doubao-seedance-2-5-260628` 与官方任务路径。
- Comfly：`doubao-seedance-2.5` 与 Comfly 任务路径。

任一请求含 `reference_video` 时，强制 `ratio: adaptive` 与 `duration: -1`。供应商差异由后端适配层处理，前端只选择供应商。

## 7. 临时公网素材

本地测试阶段使用 TempFile.org 适配器：将本地文件上传到 `POST /api/upload/local`，使用 `expiryHours: 24`。图片使用 `/{fileId}/preview`，视频使用 `/{fileId}/download`，将生成的 HTTPS URL 提交给供应商。保存 URL、文件 ID 与过期时间；提交前检查链接未过期。

TempFile.org 的使用已获用户许可。该适配器必须独立于核心业务，以便未来迁移至 TOS、OSS、COS 或自有对象存储。不得把临时 URL 当作唯一素材存档；原文件始终保留在本地项目目录。

## 8. 可靠性与错误处理

- 上传时验证文件可解码；不静默修改原视频。
- 视频理解失败明确标注失败，可重试整段或单个镜头。
- 时间段重叠、遗漏、超出时长、产品替换指令或冲突描述阻止提交。
- 创建响应不明确时保存响应摘要，不盲目重复创建任务。
- 任务 ID 创建后立即写入数据库；查询失败、前端关闭和服务重启不删除任务。
- 对可恢复的查询错误采用退避重试；允许用户按任务 ID 恢复查询。
- 生成结果保存为独立版本，并尽快下载，避免上游临时 URL 失效。

## 9. 授权与发布保护

软件不在界面显著展示作者名。发布包和服务端许可证中嵌入可验证的签名归属“王嘉祺”，用于检测授权信息与安装包篡改；不采集用户数据、不设置远程控制或隐藏后门。源代码应存放在私有仓库，正式发布时使用代码签名。

## 10. 验收标准

- 能上传一条 4–30 秒参考视频，完成分析并显示可编辑时间轴。
- 用户可以校正 AI 镜头划分，且仅受影响镜头被重新分析。
- 用户可以修改人物、背景、动作和运镜，产品无法被替换。
- 一镜到底视频保持一个连续镜头，添加编辑区间为可选能力。
- 人物图片默认转文字档案，且能选择是否作为生成参考图。
- 可选择官方或 Comfly，创建任务后可在重启后继续追踪。
- 本地素材能经 TempFile 取得 HTTPS URL 并用于供应商提交。
- 结果能直接播放/下载、保留版本并重新生成。
- API Key 不出现在前端、数据库请求摘要或日志。
