## 2. 无花销本地/API 冒烟（未向任何供应商发送）

使用测试库 + mock 网关验证：

1. **>30 秒源自动分段**：50 秒源 → 2 段，每段 ≤29 秒 ✓
2. **完整提示词含全部绝对时间块**：4 镜头 4 块，含 `00:00.00` ✓
3. **不可变版本**：人工保存 → 精修 → 卖点优化各建新版本，源 v1 文本不变 ✓
4. **原子批次**：一次请求创建 N 行（2 段 → 2 行），非每镜头一行 ✓
5. **刷新恢复**：`GET /generation-batches` 返回最新批次及其状态 ✓

冒烟未消耗任何供应商额度。

## 3. 未解决的限制（已知）

- **无损合并有兼容性约束**：每段可以独立播放/下载；全部完成后可合并下载完整视频，但片段的编码、分辨率、帧率、像素格式和音频轨道必须兼容，否则系统拒绝合并且不会通过重编码降低质量。
- **无原音频**：分段参考片段使用 `-an` 裁切，不携带原音频；`generate_audio=true` 要求 Seedance 输出音频，不等于保留原 BGM。
- **营销事实需人工审阅**：结构/规则校验通过不代表自动证明营销内容真实；提交 Seedance 前页面需用户审阅完整提示词，真实验收需人工核对卖点表达。
